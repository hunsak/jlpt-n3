JANE DOE

米津玄師 · 宇多田ヒカル · 일본어 가사 학습 노트
인트로
まるでこの世界せかいで二人ふたりだけみたいだね
마치 이 세상에 우리 둘뿐인 것 같아
なんて少すこしだけ夢ゆめをみてしまっただけ
라며 조금 꿈을 꾸고 말았을 뿐이야
💡 문장 첫머리의 なんて가 앞 줄 전체를 받아서 '…라는 (말·생각을) 하며'라는 뜻이 돼요. 두 줄이 한 문장이에요.

주요 단어

  • まるで N3
    마치 (뒤에 みたい·ようだ와 짝을 이룸)
  • 世界せかい N5
    세계, 세상
  • 二人ふたり N5
    두 사람, 둘 (불규칙 읽기)
  • 〜だけ N5
    ~만, ~뿐
  • 少すこし N5
    조금, 약간
  • 夢ゆめ N4
    꿈
  • 夢ゆめをみる N4
    꿈을 꾸다 (見{み}る를 씀. する가 아님)

문법 포인트

  • まるで〜みたいだ
    마치 ~인 것 같다. まるで가 '실제는 아니지만 꼭 그런 느낌'이라는 비유를 강조. みたいだ는 ようだ의 회화체
    まるで夢ゆめみたいだ。마치 꿈 같아.
  • 〜だね
    ~구나, ~네. 상대에게 공감을 구하는 말투. 여기선 둘만의 순간을 확인하는 느낌
  • 〜なんて (인용)
    '~라는 둥, ~라며'. 앞의 말·생각을 가볍게(때로는 자조적으로) 받는 표현. 여기선 '둘뿐인 것 같다'는 생각을 스스로 낮추며 '그런 꿈을 꿨을 뿐'이라고 정리
    合格ごうかくできるなんて思おもわなかった。합격할 수 있으리라곤 생각 못 했다.
  • 〜てしまった
    ~해 버렸다. 의도치 않게 해 버림·아쉬움. 여기선 '꿈을 꾸고 말았다' — 꾸지 말았어야 할 꿈이라는 뉘앙스
    ケーキを全部ぜんぶ食たべてしまった。케이크를 전부 먹어 버렸다.
  • 〜ただけ
    ~했을 뿐. 과거형 + だけ로 '그 이상의 의미는 없다'고 축소하는 말투
1절
つま先さきに月明つきあかり
발끝에 달빛
花束はなたばの香かおり
꽃다발의 향기
指ゆびに触ふれる指ゆび
손가락과 손가락이 맞닿아
💡 직역은 '손가락에 닿는 손가락'. 동사 없이 명사로 끝나는 체언 종지로 장면만 툭툭 보여 주는 가사 기법이에요.

주요 단어

  • つま先さき N2
    발끝 (爪先로도 씀)
  • 月明つきあかり N2
    달빛 (달이 비추는 밝음)
  • 明あかり N3
    빛, 불빛
  • 花束はなたば N2
    꽃다발
  • 香かおり N3
    향기 (좋은 냄새. 匂{にお}い보다 고운 말)
  • 指ゆび N4
    손가락
  • 触ふれる N3
    (살짝) 닿다, 접촉하다

문법 포인트

  • 체언 종지 (명사로 끝맺기)
    つま先さきに月明つきあかり처럼 동사(がある 등)를 생략하고 명사로 끝내 여운을 남기는 시적 표현
  • 〜に触ふれる
    ~에 닿다. 닿는 대상에 に를 씀 (を가 아님). 触さわる보다 '살짝, 조심스럽게' 닿는 느낌
    冷つめたい水みずに手てが触ふれた。차가운 물에 손이 닿았다.
  • 香かおり vs 匂におい
    香かおり는 좋은 향기에만, 匂におい는 냄새 전반(좋든 나쁘든)에 씀
프리코러스
さよなら もう行いかなきゃ
안녕, 이제 가야만 해
何なにもかも忘わすれて
모두 다 잊어버려
💡 〜て로 끝나는 부탁형(忘わすれてください의 생략)이에요. 문맥상 '잊어 줘'라고 상대에게 부탁하는 말.

주요 단어

  • さよなら N5
    안녕 (작별 인사. さようなら의 구어형)
  • もう N5
    이제, 벌써
  • 行いく N5
    가다
  • 何なにもかも N2
    무엇이든 모두, 전부 다
  • 忘わすれる N5
    잊다

문법 포인트

  • 〜なきゃ
    ~なければならない의 축약. '~해야 해'. 行いかなければ → 行いかなきゃ
    明日あしたは早はやく起おきなきゃ。내일은 일찍 일어나야 해.
  • 〜て (부탁)
    て형으로 끝내면 '~해 줘'라는 가벼운 부탁·명령. 忘わすれて = 잊어 줘
  • 何なにもかも vs 何なにも
    何なにも+부정은 '아무것도 (~않다)', 何なにもかも는 긍정문에서 '모조리 전부'

주요 단어

  • 硝子ガラス N1
    유리 (한자 표기)
  • 上うえ N5
    위
  • 裸足はだし N2
    맨발 (불규칙 읽기)
  • 〜まま N3
    ~한 채로, ~인 그대로
  • 歩あるく N5
    걷다
  • 痛いたむ N3
    아프다, 쑤시다 (동사. 痛{いた}い는 형용사)
  • 〜ごとに N3
    ~할 때마다, ~마다
  • 血ち N3
    피
  • 流ながれる N4
    흐르다
  • 落おちる N4
    떨어지다
  • お願ねがい N5
    부탁 (お願{ねが}い 단독으로 '부탁이야')
  • 赤あかい N5
    빨갛다, 붉다
  • 足跡あしあと N2
    발자국
  • 辿たどる N1
    (길·자취를) 더듬어 따라가다
  • 会あう N5
    만나다 (〜に会{あ}う)

문법 포인트

  • 명사 + のまま
    ~인 채로, ~인 그대로. 상태가 바뀌지 않고 이어짐. 裸足はだしのまま = 맨발인 채로
    靴くつのまま部屋へやに入はいらないで。신발 신은 채로 방에 들어오지 마.
  • 〜を歩あるく
    이동하는 '장소'에는 を를 씀. 道みちを歩あるく, 硝子ガラスの上うえを歩あるく
  • 동사 사전형 + ごとに
    ~할 때마다 (매번). 〜たびに와 비슷하지만 ごとに가 조금 더 문어적이고 '반복될 때마다 하나씩'이라는 느낌
    会あうごとに好すきになる。만날 때마다 좋아지게 돼.
  • 痛いたむ vs 痛いたい
    痛いたい는 '아프다'(형용사, 상태), 痛いたむ는 '아파 오다·쑤시다'(동사, 통증이 일어남). ごとに 앞에는 동사가 와야 하니 痛いたむ
  • 〜ていく
    ~해 가다. 화자로부터 멀어지거나 변화가 계속 진행됨. 落おちていく = 계속 떨어져 내려가다
    雪ゆきが溶とけていく。눈이 녹아 간다.
  • 〜て (부탁) + 辿たどって
    辿たどって는 '따라서'(이어지는 て)로, 会あいにきて는 '와 줘'(부탁의 て)로 쓰였어요. 같은 て형이 역할이 달라요
  • 동사 ます형 + に来くる
    ~하러 오다 (목적). 会あい + に + きて = 만나러 와 줘
    週末しゅうまつ、遊あそびに来きてね。주말에 놀러 와.

문법 포인트

  • た형 + 명사 (연체 수식)
    錆さびたプール(녹슨 수영장), 隠かくした林檎りんご(숨긴 사과), 萎しなびた君きみ(시든 너). 과거형이 명사를 꾸며 '~한 상태의'라는 뜻이 됨
    割われた窓まどを直なおした。깨진 창문을 고쳤다.
  • 수동형 放はなたれる + ていく
    放はなつ(놓아주다)의 수동 放はなたれる(풀려나다) + ていく(멀어져 가다). 금붕어가 누군가에게 풀려나 사라져 가는 장면
    鳥とりが空そらに放はなたれた。새가 하늘로 풀려났다.
  • 자동사·타동사 짝
    隠かくす(숨기다)/隠かくれる(숨다), 残のこす(남기다)/残のこる(남다). 이 가사에선 林檎りんごを隠かくした(타동), 傷跡きずあとが残のこる(자동)
  • 〜のように + 동사
    명사 + のように = ~처럼 (방식). 犬いぬのように泳およいだ = 개처럼 헤엄쳤다
    子こどものように笑わらった。아이처럼 웃었다.
  • 명사 나열 (체언 종지)
    4줄 모두 명사(金魚きんぎょ·林檎りんご·傷跡きずあと·迷子まいご)로 끝나요. 낯설고 불안한 이미지를 사진처럼 이어 붙이는 구성

    잘못, 틀림, 실수

문법 포인트

  • 〜の? (의문)
    どこにいるの? / 何なにをしているの? 문말의 の를 올려 말하면 부드러운 질문. 친한 사이 말투
  • 〜てる (〜ている 축약)
    見みている → 見みてる. 회화·가사에서 い가 빠짐. 반대로 何なにをしているの는 축약하지 않은 형태
  • 〜よ
    상대가 모르는 정보를 알려 줄 때 붙는 종조사. ここにいるよ = '(나) 여기 있어'
  • 의지형 〜そう / 〜こう
    満みたす → 満みたそう, 行いく → 行いこう. '~하자/~해야지' (권유·의지). 5단 동사는 끝 음을 お단 + う로
    一緒いっしょに帰かえろう。같이 돌아가자.
  • 〜で満みたす
    ~으로 채우다. 채우는 재료에 で. 間違まちがいで満みたそう = 잘못으로 가득 채우자
    コップを水みずで満みたす。컵을 물로 채우다.
  • 〜てよ
    て형(부탁) + よ. '~해 줘'를 조르듯 강조. 側そばにいてよ = 곁에 있어 줘
  • ます형 + に行いく
    ~하러 가다 (목적). 遊あそび + に + 行いこう = 놀러 가자. 후렴의 会あいにきて와 같은 구조
